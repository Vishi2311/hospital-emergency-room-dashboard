# Hospital Emergency Room Dashboard

An interactive Hospital Emergency Room Dashboard developed using Microsoft Excel, Power Query, Power Pivot, DAX, Pivot Tables, and Charts.

## Project Overview

This project analyzes hospital emergency room data to understand patient volume, admission trends, waiting times, patient demographics, referrals, satisfaction, and other operational performance indicators.

The dashboard is designed to help identify important trends and KPIs that can support data-driven operational decision-making.

## Tools & Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Pivot Tables
- Charts

## Key Analysis

- Total patient volume
- Admission and attendance trends
- Average waiting time
- Patient satisfaction
- Age and gender distribution
- Department referrals
- Operational KPIs
- Monthly and daily trends

## Data Preparation

Power Query was used for data cleaning and transformation.

Power Pivot was used for data modeling and relationship management.

DAX and Pivot Tables were used to calculate and analyze key performance indicators.

## Dashboard

The dashboard provides interactive visualizations to explore hospital emergency room performance and identify operational trends.
